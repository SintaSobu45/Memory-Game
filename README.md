# 🎮 Memory Battle Game (React.js)

A fun **multiplayer Memory Card Game built using React.js + Vite**

---

## 🧠 About the Project
This is a responsive memory matching game where players flip cards and try to find matching pairs.  
It supports **single-player and two-player modes**, scoring, timer, and dark mode.

---

## 🚀 Tech Stack
- ⚛️ React.js (Frontend library)
- ⚡ Vite (Fast build tool)
- 🎨 CSS3 (Custom styling)
- 🎮 JavaScript (Game logic)

---

## ✨ Features
- 👥 1 Player & 2 Player mode
- 🧠 Memory-based gameplay
- 🔢 Score tracking system
- ⏱ Timer mode (optional)
- 🌙 Dark / Light mode toggle
- 🔊 Sound effects (flip, match, win)
- 📱 Fully responsive design
- 🎨 Player-based match highlighting

---
